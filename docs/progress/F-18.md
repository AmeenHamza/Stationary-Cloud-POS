# F-18 — Terminal: search, barcode scan, category chips, sort

**Status:** COMPLETE (2026-10-31) · Phase 9 · Rules: Q22 (a scan adds one piece), rule 2 (server-paged)

## What was built

- **Search box "Search by name or scan barcode"**, focused on load:
  - Enter first tries `productByBarcode`; an exact match adds one piece and clears the box.
  - Otherwise the text becomes the name search (English, Urdu or barcode, on the server).
  - Typing alone sends nothing.
- **Category chips** ("All Products" plus each category) and **sort** (name and price, both directions).
- **Tiles** show stock (red when low), name, Urdu name and price, plus "Box Rs X" when a box price is set
  (F-33).
- **Paging and live updates:** keyset pages of 50 (`TerminalProducts`, a small `SaleProductFields`
  fragment). `stock.changed` and `product.changed` patch tiles in place; category changes refetch the page.

# F-09 — Clone per barcode

**Status:** COMPLETE (2026-10-31) · Phase 7 · Decisions: D-19, BR-04

## What was built

- `cloneProduct(input: { idempotencyKey, sourceProductId, barcode, initialStockPieces })` [K]
  (`catalog:write`). It creates a separate product copying every attribute except barcode and stock, links
  `cloned_from_id`, and records an `OPENING` movement when stock > 0. It emits `product.changed` and audits
  `product.cloned`.
- Web: "Clone with new barcode" in the product row menu. The dialog stays open: scan, "Add unit", repeat,
  and a running list of added barcodes; each unit uses its own idempotency key.

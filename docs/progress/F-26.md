**Status:** COMPLETE (2026-10-31) · Phase 8 · Rules: D-20 (purchases are amounts only, no stock), D-11,
Q25, Q33

## What was built

- **API:**
  - `vendors`, `vendor(id)` and `vendorLedger`.
  - `createVendor` / `updateVendor` [V] with "products supplied".
  - `archiveVendor` / `restoreVendor` (admins; zero balance).
  - `addVendorPurchase` ("Maal Khareeda", `PURCHASE`, amount and an optional description) and `payVendor`
    (`PAYMENT`), both [K].
  - It uses the same posting engine as customers (ADR-037) and emits `vendor.balanceChanged`.
- **Web:**
  - Admin `/vendors` and `/vendors/[id]`, built on the shared ledger components.
  - Balance wording "we owe" / "advance paid" / "Settled" (Q25).

  and payments keep the dues".

# F-33 — Piece or box at the counter, with the box price

**Status:** COMPLETE (2026-10-31) · Phase 9 · Rule: D-17

- **Adding a box:** tiles with a box price offer "Box Rs X". A cart line can switch between Piece and Box;
  switching merges with an existing line of that unit.
- **Pricing:** the server prices a box at `box_price` from the locked row. A box without a box price is
  `BAD_USER_INPUT`. Stock moves `quantity × pieces per box`, and refunds return the same pieces (D-14).
- **Tests:**
  - `sales-billing.int.spec.ts` FIN-06: box price, and pieces taken from stock.
  - `sales-refunds.int.spec.ts` FIN-16: a refunded box returns its pieces.
  - web `cart-preview.test.ts`: box line totals.

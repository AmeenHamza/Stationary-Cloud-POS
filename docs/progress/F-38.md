# F-38 — Terminal product list view

**Status:** COMPLETE (2026-11-08) · Owner update · Builds on F-18

- **The dropdown:** a new "View" dropdown sits beside the sort dropdown and offers Card view and List view.
  Each browser remembers its choice (`pos:terminal:product-view`).
- **The list:** compact rows of Product, Stock and Price, in three lists side by side (owner, 2026-11-09). A tap
  anywhere on a row adds a piece, so there is no Add button. Products with a box price also get a Box button.
  Quantities are then set in the cart, as they can be for a card.
- **Width:** the lists follow the picker's own width, not the screen's: three from 48rem, two from 36rem, one
  below that. Each row follows its own width too: one line under the headings from 24rem, and below that the name
  sits over stock and price, with no headings.
- **Network:** both views show the same server page of 50, so switching downloads nothing.
- **Tests:** E2E-15 in `counter-tools.spec.ts`.
- **Also fixed, found by NET-07:** pressing Enter did not cancel the search box's pending name search. A scan whose
  lookup outlasted that 180 ms window also sent `TerminalProducts`, which over the internet means most scans.
  Enter now cancels it, and only a code that matches nothing searches by name, as SYSTEM_DESIGN.md §3.1 says.
  `ProductSearchBar.test.tsx` reproduces it with a slow lookup.

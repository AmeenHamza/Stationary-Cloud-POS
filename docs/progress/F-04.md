# F-04 — Admin and Cashier roles

**Status:** COMPLETE (2026-10-30) · Phase 5 · Decisions: D-10, D-11 (cashier permissions)

## What was built

- **Permissions** come from `ROLE_PERMISSIONS` in `@pos/contracts` (the only role → permission map); the API's
  `AccessGuard` checks them on every handler (ADR-033); `Viewer.permissions` exposes them to the web, where
  `useCan()` only hides actions (the API always decides).
- **Role routing (web):** admins land on the admin panel (Staff until the dashboard exists, Phase 10);
  cashiers land on the billing terminal; admin-only routes send other roles home (`RequireRole`); admins can
  open the terminal from the sidebar.
- **Role changes** (F-31) revoke that user's sessions so new permissions apply at once.

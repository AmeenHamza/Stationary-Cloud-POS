# F-05 — Light/Dark theme

**Status:** COMPLETE (2026-10-30) · Phase 6

## What was built

- Design tokens for light and dark in `apps/web/src/app/globals.css` (dark keeps the old app's navy look).
- Choice per browser: Light, Dark or Match device (default), stored in `localStorage` (`pos-theme`).
- An inline bootstrap script sets the theme before first paint (no flash); `ThemeProvider` uses
  `useSyncExternalStore`, so server and client never disagree during hydration.
- Controls: a Light/Dark button on the login page; Light / Dark / Match device in the account menu.

## Tests

| Suite | Result |
|---|---|
| Web unit (`lib.test.ts`): system choice follows the OS; only known stored values accepted | PASS |
| E2E `auth.spec.ts`: the toggle switches the theme and the choice survives a reload | PASS |

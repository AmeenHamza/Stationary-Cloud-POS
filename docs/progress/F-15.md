# F-15 — Order history

**Status:** COMPLETE (2026-10-31) · Phase 9 · Rules: BR-05 (bill numbers), D-03 (no FBR column), D-12

- **API:** `orders(filter: { billNumberPrefix, status, from, to, customerId, includeArchived })`.
  - Pages: newest first, keyset pages of 50, the total only when selected.
  - Window: the last 90 days unless dated or archived (F-35).
  - `order(id)` returns an `OrderDetail` with its lines and what has been refunded.
  - Bill-number prefix search uses a `varchar_pattern_ops` partial index (ADR-038).
- **Web `/orders` (admins):**
  - Columns: Order #, date and time, subtotal, discount ("−Rs 400.00 (Flat)"), GST, total, method, status.
  - Actions per bill: reprint and refund.
  - Filters: search by bill number, status and archive.
  - Live: "N new orders" from `order.created` (no refetch per sale); `order.refunded` patches rows in
    place.
- **The same panel is the terminal's Refund modal** (F-28).

# F-20 — Bill discount (flat or percentage)

**Status:** COMPLETE (2026-10-31) · Phase 9 · Rules: BR-06, D-08 (discount before tax), D-11 (cashiers may
discount)

- **Payment dialog:** No Discount / Flat (Rs) / Percentage (%) with the value.
- **Shared parsing:** the preview and the API parse the entry with `@pos/domain` `billDiscountOf`. A flat
  discount above the subtotal, or a malformed value, shows the domain's message and blocks payment.
- **Allocation:** the discount is spread over lines (largest remainder) before tax.
- **Tests:**
  - `sales-billing.int.spec.ts` FIN-03 (D-08 1,000 − 10 % + 18 % = 1,062.00).
  - domain `bill-inputs.test.ts`.
  - web `cart-preview.test.ts` (flat above subtotal refused, percent in the sale input).
  - All PASS.

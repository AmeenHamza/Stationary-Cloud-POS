# F-28 — Terminal modals: khata, vendors, refund

**Status:** COMPLETE (2026-10-31) · Phases 8–9 · Rules: D-11 (cashiers keep khata and refund)

## What was built

- **Terminal header buttons** (`features/terminal`):
  - **Khata**: customer search, Add customer, Open khata with Add Udhaar and Receive payment. There is no
    archive here; archiving is an admin action.
  - **Vendors**: the same for suppliers.
  - **Refund**: order search by bill number and status, then Refund All or per-item refunds.
- Each modal reuses the admin panels (`CustomersPanel`, `VendorsPanel`, `OrdersPanel`). The billing screen
  stays mounted underneath, so the cart is never lost.

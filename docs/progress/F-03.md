# F-03 — Change own password

**Status:** COMPLETE (2026-10-30) · Phases 5 + 6

## What was built

- **API:** `changePassword(input: { currentPassword, newPassword })` (`@Authenticated`): checks the current
  password (wrong → `BAD_USER_INPUT` with `fieldErrors.currentPassword`), stores the new argon2id hash, revokes
  every other session of the user (this one stays signed in), audits `auth.passwordChanged`; `password` rate
  limit (5 per hour per user).
- **Validation** (`@pos/validation`): `changePasswordInputSchema` (8–128 characters, must differ) and
  `changePasswordFormSchema` (adds the confirmation, which never leaves the browser).
- **Web:** account menu → "Change password" dialog (current, new, confirm); server field errors land on the
  inputs; success toast says other devices were signed out.
